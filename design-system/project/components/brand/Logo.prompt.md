Places the Blanzo mark from the real artwork files. Use `animated` for hero moments and loaders only.

```jsx
<Logo variant="wordmark" theme="light-on-dark" height={40} base="../.." />
```

Set `base` to the relative path back to the design-system root so the image resolves. Clear space = the height of the "b" loop on all sides. Never recolour the mark: white on black, black on white, red-pink never.
