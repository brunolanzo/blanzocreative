Pill-shaped action button — use for every CTA; `primary` is the default and flips to the red-pink accent on hover.

```jsx
<Button variant="primary" size="lg" href="#contact">Start a project</Button>
```

Variants: `primary` (white fill → red-pink on hover), `accent` (red-pink fill, one per view max), `outline`, `ghost`. Sizes `sm | md | lg`. `full` stretches it. Labels are uppercase and 1–3 words.
